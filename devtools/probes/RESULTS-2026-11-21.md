## What the game does

- Inside a running game `GameSetup.setGameParameterValue` turns every write down (result 8 twice, value unchanged).
  `Configuration.editGame().setValue` works and reads back through `Configuration.getGame().getValue`.
- The game configuration keeps no empty value: an empty string reads back as `undefined`. Empty pick lists are
  stored as `|`.
- At the age change the game moves the Age setting to the new age (`AGE_EXPLORATION` read in Exploration).
- Exploration's own data load dealt every Exploration civ: 18 abilities, 18 civics trees, 32 uniques. The Antiquity
  database holds only Antiquity uniques and civics trees, which is what the transition screens were showing.
- When Workshop and Mods/ copies are both registered and enabled, the game served the Workshop files even with
  Modding.log naming the Mods/ modinfo. The first game ran old code and its checks don't count; the second ran with
  the Workshop row switched off.
